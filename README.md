# PBLS 專案：互動式醫療情境學習平台

## 專案簡介

PBLS 專案是一個主要目的是在提供醫護人員一個互動式醫療情境學習體驗的平台。它結合了360 度實境教學影片、虛擬人模擬情境、筆試測驗和VR實際操作，幫助使用者在多種模式下學習和練習醫療急救知識。平台設計注重使用者體驗，提供清晰的介面、豐富的內容和即時的回饋機制。

## 主要功能
### 1. 資訊頁面 (Information)

*   **PBLS平台全站簡介**：醫療跑馬燈上顯示。
*   **PBLS流程圖**：專業醫師提供的流程圖。
*   **PBLS知識庫**：內含一般教科書可以看到的所有知識點。
*   **PBLS情境處置**：說明不同情境需要做的處理措施，更好的讓使用者操作後續情境模擬對話部分。
*   **跳轉按鈕**：可以直接點選「進入練習專區」以及「進入測驗專區」按鈕，直接挑轉到想要練習的模組，位於頁面底部。

### 2. 練習專區 (Practice Area)

練習專區分為兩個主要部分：

#### a. 360 實境教學影片 (360 VR Teaching Videos)

*   **沉浸式學習**：已嵌入virti平台編輯好的360實境教學影片，可放大全螢幕觀看。
*   **討論區設計**：所有使用者可以在討論區留言，分享經驗。
*   **返回按鈕**：提供「返回練習專區」按鈕，位於頁面底部。

#### b. 虛擬人模擬 (Virtual Human Simulation)

*   **情境選擇**：透過選單選擇五種不同的醫療情境教案（心臟驟停、食物中毒、溺水、火災嗆傷、外傷）。
*   **詳細情境描述**：選擇情境後，顯示該情境的詳細描述和相關圖片。
*   **情境模擬對話訓練**：嵌入virti平台製作的AI虛擬人物，虛擬人誤會模擬所選擇情境遇到的狀況問題，使用者需下達"下一步該怎麼做"的指令，使用者需要在限制時間內完成所有目標點，若有模糊，不知該如何進行的部分，可以點擊設計好的hint圖示來獲取提示。
*   **回饋建議**：針對使用者的下達指令內容會判斷是否跟預設內容一致或相近，給予分數以及相關建議，會顯示每個目標店的完成度，每個目標點也有相關建議。
*   **返回按鈕**：提供「返回練習專區」按鈕，位於頁面底部。

### 3. 測驗專區 (Practice Area)

測驗專區分為兩個主要部分：

#### a. 筆試測驗 (Exam Area - Written Test)

*   **題庫擴充**：將原本測試的20題擴增至200題，隨機抽20題考，且每次考試選項順序不一樣。
*   **難易度標示**：將難易度用情緒來標示，增加使用者體驗。
*   **即時回饋**：測驗結束後提供詳細的回饋頁面(分數、動畫、答題數、總題數、答題時間以及詳解說明)。
*   **返回按鈕**：提供「返回測驗專區」按鈕，位於頁面底部。

#### b. VR操作訓練

*   **操作指南**：這個部分訓練內容、操作指南。
*   **VR操作模擬**：透過VR頭盔，操作模擬急診室的所有物件，在限時三分鐘內完成所有急救操作流程，需依照關卡設計順序完成。
*   **自我評量功能**：使用者記錄測驗時間以及完成度，並根據每一關每一個步驟填寫自我評量表，可以讓使用者在次複習，更熟悉每一個關卡的操作步驟細節。
*   **返回按鈕**：提供「返回測驗專區」按鈕，位於頁面底部。

  
### 4. 歷史成績 (History)

*   **成績記錄**：記錄使用者過往的測驗和練習成績(包刮:情境模擬對話、筆試測驗、VR操作測驗)。
*   **學習紀錄**：對帳戶測驗做簡單統整，依照上線時間顯示學習時間。

### 5. 團隊成員 (Team)

*   **成員介紹**：專題成員、指導老師、致謝人員。

### 5. 全站通用設計 (Global Design)

*   **固定背景**：全站（除登入/註冊頁面外）採用一張固定的醫療主題背景圖片，位於最底層，不阻擋點擊。
*   **毛玻璃卡片**：主要內容區塊和卡片（如測驗選項、練習選項、情境卡片、歷史成績卡片、團隊成員卡片）均採用半透明毛玻璃效果，讓背景圖片透出，提升視覺質感。
*   **透明背景**：所有主要容器的白色背景已替換為透明，以確保毛玻璃效果的正確呈現。
*   **標題對齊**：測驗專區、練習專區、歷史成績和團隊成員頁面的主標題和副標題已調整，確保與頂部導航欄保持適當間距，並居中對齊。

### 6. 登入與註冊頁面 (Login & Register Pages)

*   **獨立背景**：登入和註冊頁面不使用全站固定背景，而是採用獨立的漸變背景。
    *   登入頁面背景已更新為與註冊頁面相同的淡紫色漸變。
*   **登入按鈕**：登入頁面的按鈕已修改為醒目的紅色漸變，並調整了懸停效果和陰影。
*   **毛玻璃風格**：登入和註冊容器也應用了增強的毛玻璃效果，保持簡潔專業的風格。

## 技術棧

*   **前端**：HTML5, CSS3, JavaScript
*   **資料**：JSON (用於題目管理)
*   **動畫**：CSS `@keyframes` 動畫, JavaScript (用於動態元素操作)
*   **圖片處理**：Python Pillow (用於生成動畫幀，儘管最終動畫改為 CSS/JS 實現)

## 功能特色

### 🎯 互動式學習體驗
- 多種學習模式：筆試測驗、360度影片、虛擬情境模擬
- 即時回饋機制：測驗結果、動畫鼓勵、詳細分析
- 難易度分級：題目難度標示，幫助學習者循序漸進

### 🎨 現代化UI設計
- 毛玻璃效果：半透明卡片設計，提升視覺質感
- 響應式設計：支援桌面、平板、手機等多種裝置
- 統一風格：全站一致的設計語言和色彩搭配

### 🏥 醫療情境模擬
- 五種情境：心臟驟停、食物中毒、溺水、火災嗆傷、外傷
- 詳細描述：每個情境都有具體的醫療場景描述
- 視覺化展示：情境圖片和圖示，增強學習效果

### 📊 學習追蹤
- 成績記錄：歷史測驗成績追蹤
- 進度管理：學習進度和完成度統計
- 個人化體驗：使用者帳戶和個人化設定
